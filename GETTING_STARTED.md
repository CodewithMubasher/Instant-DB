# 🚀 Getting Started with Instant-DB

Get up and running with Instant-DB in seconds!

---

## ⚡ Super Quick Start (30 seconds)

### Option 1: Direct Download
1. [Download index.html](https://github.com/CodewithMubasher/Instant-DB/releases)
2. Double-click to open in browser
3. Done! 🎉

### Option 2: Clone Repository
```bash
git clone https://github.com/CodewithMubasher/Instant-DB.git
cd Instant-DB
open index.html  # macOS
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```

### Option 3: Online Access
- Use GitHub Pages (if enabled)
- No download needed
- Access from any device

---

## 📊 Load Your Database

### Method 1: Drag & Drop
```
1. Drag your .db file onto the window
2. Drop to load
3. Done!
```

### Method 2: Click to Browse
```
1. Click "Load Database" button
2. Select your .db file
3. Wait for load
```

### Method 3: Use Sample Data
```
1. Click "Sample Data" button
2. Load demo database
3. Explore features
```

## 🎯 First Steps

### Step 1: Explore the Interface
```
Left Sidebar     → List of all tables
Main Grid        → Data display
Top Toolbar      → Tools and options
Right Panel      → Table info
```

### Step 2: View Your Data
```
1. Click a table name in sidebar
2. See data in main grid
3. Scroll to explore
```

### Step 3: Try a Simple Edit
```
1. Click any cell
2. Type new value
3. Press Enter
4. See it update
```

### Step 4: Practice Undo
```
1. Click Undo (or Ctrl+Z)
2. See change revert
3. Click Redo to restore
```

## 🔍 Common Tasks

### Search Data
```
Click 🔍 → Type value → See results
```

### Filter Rows
```
Click column header → Choose Filter → Set condition → Apply
```

### Sort Data
```
Click column header → Choose Ascending/Descending
```

### View Relationships
```
Click "ER Diagram" → See table relationships
```

### Write SQL Query
```
Click "SQL Editor" → Write query → Execute
```

## 💡 Pro Tips

### Tip 1: Keyboard Shortcuts
- `Ctrl+F` or `Cmd+F` → Search
- `Ctrl+Z` or `Cmd+Z` → Undo
- `Ctrl+Y` or `Cmd+Y` → Redo
- `Enter` → Confirm edit
- `Escape` → Cancel edit

### Tip 2: Performance
- Works with 1M+ rows
- Uses virtual scrolling
- No lag, even with huge datasets
- Keep browser updated for best performance

### Tip 3: Data Safety
- All processing in browser
- Your data stays local
- No uploads to servers
- Works completely offline

### Tip 4: Dark Mode
- Click theme button (🌙/☀️)
- Great for long sessions
- Eye-friendly interface
- Auto-saves preference

## 🆘 Troubleshooting

### Database won't load?
```
✓ Make sure it's a valid SQLite file (.db, .sqlite, .sqlite3)
✓ Try sample data first to test
✓ Check browser console for errors (F12)
✓ Try different browser
```

### Edits not working?
```
✓ Make sure cell is not locked
✓ Try editing different cell
✓ Refresh page (Ctrl+R)
✓ Check browser console
```

### Performance issues?
```
✓ Reduce number of active filters
✓ Close other browser tabs
✓ Restart the application
✓ Use recent browser version
```
