# 🤝 Contributing to Instant-DB

Thank you for your interest in contributing to Instant-DB! We welcome contributions from everyone.

---

## 📋 Code of Conduct

We are committed to providing a welcoming and inspiring community for all.

**Be respectful, inclusive, and constructive.**

---

## 🚀 How to Contribute

### 1. Report a Bug 🐛

Found a bug? Let us know!

**Before reporting:**
- Check if issue already exists
- Test with latest version
- Gather error details

**When reporting:**
- Use clear title
- Describe the issue
- Steps to reproduce
- Expected vs actual behavior
- Screenshots/videos if helpful

[📝 Report a Bug](https://github.com/CodewithMubasher/Instant-DB/issues/new?template=bug_report.md)

---

### 2. Suggest a Feature 💡

Have a great idea? We'd love to hear it!

**Good feature ideas:**
- Solve real problems
- Align with Instant-DB vision
- Respect the single-file philosophy

**When suggesting:**
- Explain the use case
- How it helps users
- Example or mockup
- Alternative solutions

[🎯 Suggest a Feature](https://github.com/CodewithMubasher/Instant-DB/issues/new?template=feature_request.md)

---

### 3. Improve Documentation 📚

Help us explain Instant-DB better!

**Documentation improvements:**
- Fix typos or unclear sections
- Add examples
- Improve organization
- Translate to other languages
- Create tutorials

**How to contribute:**
1. Fork the repository
2. Edit documentation files
3. Submit a pull request
4. We'll review and merge

---

### 4. Submit Code 💻

Ready to code? Great!

#### Before Starting

- **Check existing issues/PRs** - Don't duplicate work
- **Discuss first** - For major changes, open an issue first
- **Single-file philosophy** - Keep index.html as single file
- **No external dependencies** - Use CDN links only

#### Development Setup

```bash
# Clone the repo
git clone https://github.com/CodewithMubasher/Instant-DB.git
cd Instant-DB

# Open in browser
open index.html

# Make your changes
# Test in multiple browsers
# No build process needed!
```

#### Code Style

```javascript
// ✅ Good: Clear and concise
function loadDatabase(file) {
  // Process file
}

// ❌ Avoid: Unclear naming
function lddb(f) {
  // Process
}
```

```css
/* ✅ Good: Use CSS variables */
color: var(--foreground);
background: var(--sidebar);

/* ❌ Avoid: Hardcoded colors */
color: #1a1a1a;
background: #f5f5f5;
```

#### Before Submitting PR

- [ ] Code follows style guide
- [ ] Changes tested in browsers (Chrome, Firefox, Safari)
- [ ] No console errors
- [ ] Documentation updated if needed
- [ ] Commit message is clear

## 🔄 Pull Request Process

### 1. Fork & Branch
```bash
# Fork the repo
# Clone your fork
git clone https://github.com/YOUR_USERNAME/Instant-DB.git

# Create feature branch
git checkout -b feature/my-feature
```

### 2. Make Changes
```bash
# Edit files
# Test thoroughly
git add .
git commit -m "Add my feature"
```

### 3. Push & Create PR
```bash
git push origin feature/my-feature
```

Then create a pull request with:
- **Clear title** describing the change
- **Description** explaining what/why
- **Screenshots** for UI changes
- **Testing notes** how you tested it

### 4. Review & Iteration
- Maintainer reviews your PR
- Respond to feedback
- Make requested changes
- PR gets merged when approved

## 📊 Contribution Guidelines

### What We're Looking For

✅ **Welcome:**
- Bug fixes
- Performance improvements
- New features (aligned with vision)
- Documentation improvements
- Accessibility enhancements
- Code optimization

❌ **Not Accepting:**
