# Instant-DB

> Ultra-fast, single-file database viewer, editor, analytics workspace, and AI-powered database assistant.

No installation. No setup. No signup. No subscriptions.

Open a single HTML file and start working instantly.

![Main Dashboard](assets/main-dashboard.png)

## Why Instant-DB?

I built Instant-DB because existing database tools felt either:

* Outdated
* Heavy
* Overwhelming
* Locked behind paywalls

Instant-DB focuses on speed, simplicity, and a calm user experience while providing powerful database management capabilities.

### Highlights

* ⚡ Tested with 1,000,000+ rows
* 🎨 Modern shadcn-inspired design system
* 🧠 Optional AI Assistant (Bring Your Own API Key)
* 🗺️ Interactive ER Diagram
* ✏️ Inline Editing + Undo/Redo
* 📊 Data Profiling & Analytics
* 🔍 Global Search, Filters & Query History
* 🌙 Dark & Light Themes
* 📁 Single HTML File
* 🔓 Fully Open Source
